# Desktop Agentic System

Minimal desktop agentic system with a Tkinter chat UI, LLM routing/execution, and filesystem tools.

## Setup

```bash
python -m venv .venv
# Windows
.\.venv\Scripts\Activate.ps1
# macOS/Linux
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Test

```bash
pytest -q
```

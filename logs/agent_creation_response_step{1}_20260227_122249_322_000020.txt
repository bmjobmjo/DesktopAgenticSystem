INTERNAL WORKFLOW (LOOP PREVENTION)

1. **Analyze Query**: Determine if the user is asking for information that can be found in files or the repository. Look for keywords like "document", "file", "policy", "procedure", "guide", "manual", "spec", "requirements", etc. Set `needs_file_search` accordingly.

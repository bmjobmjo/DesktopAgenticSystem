DATABASE SCHEMA REFERENCE
====================================================
**Tasks table:**
- id (INTEGER PRIMARY KEY)
- title (TEXT NOT NULL)
- description (TEXT)
- status (TEXT DEFAULT 'open') - values: 'open', 'scheduled', 'in_progress', 'completed', 'cancelled'
- scheduled_date (DATETIME)
- due_date (DATETIME)
- priority (TEXT DEFAULT 'medium') - values: 'low', 'medium', 'high'
- assigned_to (TEXT)
- created_by (TEXT)
- created_at (DATETIME DEFAULT CURRENT_TIMESTAMP)
- updated_at (DATETIME DEFAULT CURRENT_TIMESTAMP)
- completed_at (DATETIME)
- is_active (BOOLEAN DEFAULT 1)

**TaskNotes table:**
- id (INTEGER PRIMARY KEY)
- task_id (INTEGER NOT NULL)
- note_content (TEXT NOT NULL)
- created_by (TEXT)
- created_at (DATETIME DEFAULT CURRENT_TIMESTAMP)
- is_internal (BOOLEAN DEFAULT 0)

**Functions:**
- CREATE TASK: Insert into Tasks with required title; optional fields: description, priority, assigned_to, due_date, scheduled_date. Set created_by=USERNAME, status='open'.
- SCHEDULE TASK: Update Tasks set scheduled_date and status='scheduled' (if open). Use task id or title to identify.
- CLOSE TASK: Update Tasks set status='completed', completed_at=CURRENT_TIMESTAMP.
- ADD NOTE: Insert into TaskNotes (task_id, note_content, created_by, is_internal). First find task_id if not provided.
- LIST TASKS: Select from Tasks with optional filters (status, assigned_to, priority, date ranges). Order by priority (high>med>low), due_date ASC, created_at DESC.
- SEARCH TASKS: Use LIKE on title and description: WHERE title LIKE '%term%' OR description LIKE '%term%'.
- BULK ADD: Parse text input where each line defines a task. Extract fields, then create tasks in a transaction.

Use execute_sql tool. Always parameterize queries. Use CURRENT_TIMESTAMP for timestamps when appropriate.
